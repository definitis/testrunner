# TestRunner

Учебное расширение VS Code для проверки консольных программ C++17.

Установка зависимостей: `npm install`. Сборка: `npm run compile`.
Откройте эту папку в VS Code и нажмите F5 для запуска расширения.

## Тестовые файлы

В окне Extension Development Host откройте папку со своим сохранённым `.cpp`.
Сделайте вкладку исходника активной и через Ctrl+Shift+P выполните
`TestRunner: Add Test`. Откроются `test1.in` для входных данных и `test1.out`
для ожидаемого ответа. Заполняйте и сохраняйте их обычным редактором.
Перед добавлением следующего теста вернитесь во вкладку `.cpp`.

Тесты хранятся в `.testrunner/<имя исходника>/` внутри проекта.
Для `tasks/main.cpp` используется `.testrunner/tasks/main/`, поэтому вложенные
исходники с одинаковыми именами не смешивают тесты. Новые пары получают
следующий свободный номер и не перезаписывают существующие файлы.

`TestRunner: Open Tests` показывает список файлов тестов активного `.cpp`.
Удалять тесты можно через проводник VS Code, удаляя оба файла пары.
Тесты сохраняются после закрытия редактора. Компиляция и выполнение пока
не подключены к команде `Run All Tests`; она показывает сообщение об этом.

## Компиляция C++

В `src/runner.ts` добавлена функция `compile`: она компилирует один исходник
через `g++ -std=c++17` и возвращает путь к программе во временном каталоге.
Функция `cleanup` удаляет этот каталог после использования.
Пути передаются отдельными аргументами без shell, поэтому пробелы в именах
не требуют ручного экранирования. Нужен установленный g++ в `PATH`.

Диагностика компилятора ограничена 1 МиБ, время компиляции — 30 секундами.
Ошибки компиляции и отсутствие g++ сообщаются отдельно. При ошибке временный
каталог удаляется. Подключение компиляции и запуска к редактору будет дальше.
